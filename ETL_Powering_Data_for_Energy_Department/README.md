# Powering Data for the Department of Energy - Building an ETL Pipeline

## Overview
This project focuses on building an ETL (Extract, Transform, Load) pipeline to process and organize energy-related data for the Department of Energy. The pipeline extracts raw data, transforms it into a clean and structured format, and loads it for further analysis.

## Objectives
- Extract data from raw sources  
- Clean and transform data for consistency and usability  
- Load processed data into a structured format for analysis  

## Tools & Skills
- Python  
- Pandas  
- ETL Pipeline Design  
- Data Cleaning & Transformation  

## Key Learnings
- Understanding end-to-end ETL workflow  
- Handling real-world messy datasets  
- Structuring data for analytical use cases
